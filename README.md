# Spam Email Classifier

A Machine Learning web application that detects whether a message is Spam or Not Spam.

## Features

* Predict spam messages
* Simple user interface
* Fast prediction
* Live deployed website

## Technologies Used

* Python
* Scikit-learn
* Streamlit
* Pandas
